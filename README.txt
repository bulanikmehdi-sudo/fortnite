FORTNITE MAP EXPLORER

So verwendest du es:
1. Entpacke diese ZIP-Datei.
2. Lade den Inhalt des Ordners in ein neues GitHub-Repository hoch.
3. In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Nach kurzer Zeit zeigt GitHub deine Website-Adresse unter Settings > Pages.

Wichtig: Enthalten ist der Datenindex mit 229 Versionen. Kartenbilder und einzelne POI-JSON-Dateien waren nicht Teil der bereitgestellten Markdown-Datei und sind deshalb nicht in diesem Paket.
